### 💰 Enterprise Financial Suite & Advanced DAX Analytics
A 4-page executive financial suite in Power BI built from **raw, uncleaned ERP/GL accounting data** — diagnosing and fixing 3 critical data-integrity flaws (sign-convention conflicts, a $26.74M budget miscategorized under a single placeholder account, and broken relational links) using an advanced, DAX-only data-cleansing layer.

- 🛠 Engineered a **programmatic data-cleansing layer entirely in DAX** — contextual sign inversion with `SUMX`, and virtual relationship bridging with `TREATAS` — without touching the live source database
- 💵 **Cash Flow & Runway** page projects a rolling **$26.65M ending cash balance** and an automated **45.31-month runway** estimate
- 📄 **AR Aging & Collections** dynamically buckets **$1.27M in outstanding receivables** (0-30 / 31-60 / 61-90 / 91+ days) with geographic risk mapping
- 📊 **Budget vs. Actual** isolates 24 over-budget accounts via dynamic variance analysis across a $26.74M budget

🔹 **Tools:** Power BI · DAX (`TREATAS`, `SUMX`, `CALCULATE`) · Power Query · M-Code · Financial Modeling
🔗 **Repository:** [enterprise-financial-suite-dax-analytics](https://github.com/mohamed-sabri-analyst/enterprise-financial-suite-dax-analytics)
